# 📖 Project Overview

The **AI-Powered Medicine Supply Chain Optimizer** is a full-stack healthcare application developed to improve medicine inventory management across hospitals.

The system enables administrators to manage hospitals, medicines, and inventory while providing AI-based stock analysis, alerts for low-stock medicines, and transfer recommendations between hospitals. The application improves medicine availability, reduces wastage, and supports better decision-making.

# 🚀 Installation

### Clone Repository

```bash
git clone https://github.com/Twinkle-14/medicine-supply-chain-optimizer.git
```

```bash
cd medicine-supply-chain-optimizer
```

### Backend Setup

```bash
cd backend

python -m venv venv

# Windows
venv\Scripts\activate

pip install -r requirements.txt

uvicorn app.main:app --reload
```

### Frontend Setup

```bash
cd frontend

npm install

npm run dev
```
